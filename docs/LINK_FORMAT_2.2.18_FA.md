# نسخهٔ ۲.۲.۱۸ — فقط «لینک خصوصی» پذیرفته می‌شود

> **خلاصهٔ یک‌خطی:** از این نسخه، سفارش فقط با **لینک خصوصی (دعوت)** تلگرام ثبت می‌شود؛ هر قالب دیگری
> همان‌جا رد می‌شود و پیام «❌ لینک درست را بفرستید» با قالب صحیح نمایش داده می‌شود — بدون کسر پول و بدون ثبت سفارش.

---

## ۱) قالب‌های پذیرفته‌شده

همهٔ این شکل‌ها یک لینک معتبرند و به شکل استاندارد ذخیره می‌شوند:

| ورودی کاربر | ذخیره‌شده |
|---|---|
| `https://t.me/+AbCdEf123456` | `https://t.me/+AbCdEf123456` |
| `t.me/+AbCdEf123456` | `https://t.me/+AbCdEf123456` |
| `+AbCdEf123456` | `https://t.me/+AbCdEf123456` |
| `telegram.me/+AbCdEf123456` · `www.t.me/+AbCdEf123456` | `https://t.me/+AbCdEf123456` |
| `https://t.me/joinchat/AbCdEf123456` | `https://t.me/joinchat/AbCdEf123456` |
| `tg://join?invite=AbCdEf123456` | `https://t.me/+AbCdEf123456` |
| `https://t.me/+AbCdEf123456?join=1` (پارامتر اضافه) | `https://t.me/+AbCdEf123456` |

## ۲) قالب‌های رد‌شده (سفارش اصلاً ساخته نمی‌شود)

- لینک **عمومی**: `@mygroup` یا `t.me/mygroup` یا `https://t.me/mygroup`
- لینک **پیام/موضوع**: `https://t.me/mygroup/123` یا `https://t.me/c/1234567890/12`
- **دامنهٔ دیگر**: `https://example.com/...`
- **متن نامربوط**: «سلام»، توضیح فارسی، هر چیزی که لینک نیست
- لینک ناقص/کوتاه: `https://t.me/+abc` (هش کوتاه‌تر از ۸ کاراکتر) یا `https://t.me/+`

پیام خطا همیشه **قالب درست** را نشان می‌دهد:

> ❌ این لینک «عمومی» است و پذیرفته نمی‌شود.
> فقط لینک خصوصیِ دعوت درست است:
> `https://t.me/+AbCdEf123456`

و در پایان: «🔙 برای انصراف «🔙 انصراف» را بزنید.»

## ۳) در کجای مسیر بررسی می‌شود؟

1. **همان لحظهٔ گرفتن لینک:** کاربر لینک را می‌فرستد؛ اگر قالب درست نباشد، وارد مرحلهٔ انتخاب زمان نمی‌شود و
   کاربر می‌تواند بلافاصله لینک درست را بفرستد (بدون خروج از فرایند خرید).
2. **دوباره پیش از پرداخت:** اگر لینک بین دو مرحله تغییر کرده باشد یا از نشست قبلی مانده باشد، پیش از
   `purchase_order_atomic` دوباره اعتبارسنجی و نرمال می‌شود؛ لینک بد ⇒ بازگشت به مرحلهٔ لینک و **هیچ کسری/ثبتی**.
3. **هنگام ذخیره:** لینک همیشه به شکل استاندارد ذخیره می‌شود؛ در نتیجه قفل تداخل زمانی برای یک گروه،
   حتی اگر کاربر شکل‌های مختلف همان لینک را بفرستد، درست کار می‌کند (مقایسه با کلید نرمال‌شده انجام می‌شود).

## ۴) کلیدهای تنظیم

```env
# private = فقط لینک خصوصی (پیش‌فرض) | any = هر متن غیرخالی (رفتار قدیمی)
ORDER_LINK_MODE=private

# (اختیاری) الگوی دقیق‌ترِ خودتان؛ اگر خالی باشد اعتبارسنجی پیش‌فرض استفاده می‌شود:
# ORDER_LINK_REGEX=^https://t\.me/\+[A-Za-z0-9_-]{16,}$
```

- اگر روزی خواستید موقتاً سخت‌گیری را بردارید (مثلاً گروهی که لینک عمومی دارد)، فقط `ORDER_LINK_MODE=any`
  بگذارید و ربات را ری‌استارت کنید؛ با `private` همه چیز به حالت سخت‌گیر برمی‌گردد.

## ۵) تست‌ها

- ۱۸ تست در `tests/test_order_link_validation.py`:
  قبول ۱۵ شکل مختلف لینک خصوصی، رد ۱۴ ورودی نامعتبر، نرمال‌سازی، پیام خطای درست،
  رد شدن در مسیر پرداخت (بدون کسر پول)، نرمال‌سازی هنگام ذخیره، و مقایسهٔ کلید گروه در قفل زمانی.
- مجموع کل: **۴۴۹ تست موفق بدون skip** (شامل ۴۹ تست PostgreSQL واقعی).

## ۶) دستورات نصب

```bash
cd /root/tgcallbot

docker compose exec -T db pg_dump -U postgres tgcallbot > backup-$(date +%F-%H%M).sql

git fetch origin
git switch arena/01a0b5c9-tgcallbot 2>/dev/null || git switch -c arena/01a0b5c9-tgcallbot origin/arena/01a0b5c9-tgcallbot
git pull --ff-only

grep -q ORDER_LINK_MODE .env || cat >> .env <<'EOF'

ORDER_LINK_MODE=private
EOF

docker compose up -d --build --no-deps bot
docker compose logs -f bot --tail=100
```

پس از نصب، در لاگ باید `BOT_VERSION = 2.2.18` و برای هر لینک رد‌شده خط
`Order link rejected: '...'` را ببینید.
