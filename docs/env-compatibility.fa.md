# هشدار سازگاری تنظیمات سرور با پیش‌نویس ۲.۳.۱۴

> **این نسخه با تمام گزینه‌های `.env` شاخه‌های قبلی سازگار نیست؛ روی سرور موجود به اسم «نسخهٔ کامل» نصب نشود.** این سند فقط نام گزینه‌ها را بررسی می‌کند. هیچ رمز، توکن، URL عملیاتی یا کلید سشنی را در گفتگو، Issue، لاگ یا Git ارسال نکنید.

وضعیت مشاهده‌شدهٔ سرور در ۲۴ سپتامبر ۲۰۲۶: checkout و کانتینر روی ۲.۳.۱۲ (`0a627e1`) بودند. پرس‌وجوی خواندنی در یک لحظه شمار سفارش‌های `running`/`pending`/زمان‌بندی‌شدهٔ نزدیک را صفر نشان داد و سفارش ۸۴۶ را `completed` با تایمرِ شروع‌شده؛ این مشاهده **ثبات تماس، تسویهٔ درست گذشته و بی‌کار ماندن سرور در آینده** را اثبات نمی‌کند. پیش از استقرار دوباره بررسی شود؛ maintenance باید از پنل روی ربات اصلی و نمایندگی‌ها فعال و نبود سفارش فعال/پرداخت معلق تأیید شود.

## گزینه‌هایی که نسخهٔ فعلی به آن‌ها عمل نمی‌کند

| گزینهٔ موجود در برخی `.env`های عملیاتی | وضعیت کد این شاخه |
| --- | --- |
| `VOICE_JOIN_SEQUENTIAL` و `VOICE_JOIN_SEQUENTIAL_*` | شاخهٔ فعلی فقط موج‌های تطبیقی را اجرا می‌کند؛ `VOICE_JOIN_INITIAL_CONCURRENCY=1` فقط موج اول است و ترتیب دائمی را تضمین نمی‌کند. |
| `VOICE_JOIN_ACCOUNT_GAP_*` | این نام‌ها برای فاصلهٔ ورود خوانده نمی‌شوند. فاصلهٔ مؤثر تابع تنظیمات stagger و پروفایل ضداسپمِ پنل/DB است. |
| `VOICE_SECOND_CHANCE_*` | دورهای شانس دوم و زمان انتظار مربوطه پیاده‌سازی نشده‌اند. `VOICE_ACCOUNT_ATTEMPT_LIMIT=0` در executor به **۱ تلاش** تبدیل می‌شود، نه نامحدود. |
| `VOICE_SILENCE_MODE`، `VOICE_LISTENER_*` | حالت listener/auto این شاخه وجود ندارد. مسیر فعلی از استریم سکوت استفاده می‌کند؛ صرفاً گذاشتن `auto` مدیای سبک‌تر فعال نمی‌کند. |
| `ORDER_LINK_MODE`، `VOICE_SESSION_CONFLICT_RETRY_SECONDS`، `VOICE_IDLE_REAPER`، `VOICE_IDLE_CLIENT_TTL` | این سوئیچ‌ها در کد فعلی اثر ندارند؛ از آن‌ها برای تضمین رفتار سفارش یا پایداری سشن استفاده نکنید. |
| `BOT_MEM_LIMIT`، `BOT_CPU_LIMIT`، `VOICE_RAM_SOFT_LIMIT_MB` | این گزینه‌ها حد منابع/حافظهٔ Compose یا برنامه را مطابق مقدار `.env` تغییر نمی‌دهند. |

`VOICE_JOIN_MAX_CONCURRENCY` سقف است، نه دستور ورود به تعداد آن؛ محدودیت هم‌زمانی سراسری، Join Brain و تنظیم ضداسپمِ پنل ممکن است عدد مؤثر را تغییر دهند. `MAX_CONCURRENT_ORDERS` در Config خوانده می‌شود، ولی مسیر فعلی ثبت سفارش آن را به‌عنوان سقف اجرا نمی‌کند. `BOT_MEM_LIMIT`/`BOT_CPU_LIMIT` نیز در Compose فعلی اعمال نمی‌شوند: حدود حافظه/پردازندهٔ ربات در `docker-compose.yml` ثابت هستند. وجود مقدار در `.env` نشانهٔ پشتیبانی آن گزینه نیست.

برای جلوگیری از استقرار با فرض نادرست، `deploy-warp.sh` پیش از هر Docker/backup تنظیمات مهمِ نادیده‌گرفته‌شده را **با بررسی وجود نام کلید** شناسایی می‌کند و بدون چاپ مقدارها متوقف می‌شود. این گارد فقط پس از به‌روزرسانی فایل‌های پروژه فعال است؛ اسکریپت قدیمیِ روی سرور چنین حفاظتی ندارد. **گزینه‌ها را صرفاً برای دور زدن گارد حذف نکنید**؛ ابتدا رفتار موردنیاز باید در کد ادغام و با آزمون آفلاین و سپس زنده تأیید شود.

## امنیت و ترتیب کار

- نسخهٔ مشاهده‌شده پورت PostgreSQL را روی همهٔ اینترفیس‌ها (`5432`، IPv4 و IPv6) منتشر می‌کند. اگر از بیرون باز است، ورودی عمومی TCP 5432 را **در فایروالِ ارائه‌دهنده** محدود کنید؛ پورت Docker ممکن است از قوانین UFW عبور کند. بستن در فایروالِ ارائه‌دهنده به restart نیاز ندارد و شبکهٔ خصوصی کانتینرها را تغییر نمی‌دهد.
- اسرار ارسال‌شده در گفتگو باید افشاشده فرض شوند. چرخش توکن ربات، رمز PostgreSQL و API credentials باید با برنامهٔ توقفِ کوتاه و بکاپِ خصوصی انجام شود؛ صرف تغییر `POSTGRES_PASSWORD` در `.env` رمز DB موجود را تغییر نمی‌دهد. برای جلوگیری از قطع سفارش جدید، maintenance را از پنل هماهنگ کنید.
- `SESSION_ENCRYPTION_KEY` را **بدون بکاپِ معتبر و مهاجرت رمزنگاری سشن‌ها تغییر ندهید**؛ در غیر این صورت اکانت‌ها از DB بازخوانی نمی‌شوند. هیچ SessionString یا کلید Fernet را چاپ/ارسال نکنید.
- لینک‌هایی که در پیام‌رسان به‌صورت `[نام](URL)` نمایش داده می‌شوند، اگر همین نویسه‌ها واقعاً داخل `.env` ذخیره شده باشند مقدار معتبر URL نیستند؛ فقط خود URL باید در فایل باشد. مقدار واقعی URL را برای بررسی نفرستید.
- هیچ `docker compose down/up/restart`، checkout/fetch برای استقرار، چرخش یک‌طرفهٔ کلید، اصلاح دستی تراکنش یا اجرای پروب MTProto موازی صرفاً بر پایهٔ شمار DB انجام نشود. برای ادامهٔ بررسی، فقط شمار/وضعیت سفارش‌ها، maintenance و تأیید وجود یا نبود تماس واقعی نیاز است.

پیش‌نویس PR شمارهٔ ۱۸ برای بازبینی است، نه مجوز نصب. [راهنمای استقرار](deploy-final.fa.md) تا تکمیل سازگاریِ درخواستی و کنترل پیش‌شرط‌ها نباید به‌عنوان دستور نهایی اجرا شود.
