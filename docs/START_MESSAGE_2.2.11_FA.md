# نسخهٔ ۲.۲.۱۱ — پیام استارت حرفه‌ای و قابل تنظیم

این نسخه روی ۲.۲.۱۰ ساخته شده است؛ رفع محدودیت CPU/RAM، حسابداری و عودت دقیق، ترتیب گزارش شروع/پایان، امکانات نمایندگی و پریمیوم دست‌نخورده‌اند.

## فعال‌سازی و تنظیم از داخل ربات

پس از نصب نسخه، با حساب سوپرادمین وارد شوید:

**پنل مدیریت → تنظیمات → 📝 تنظیم متن استارت**

- **✨ قالب پیشنهادی:** متن قبلی همین ربات را با قالب جدید جایگزین و ذخیره می‌کند؛ پارامترهای برند را پاک نمی‌کند.
- **👁 پیش‌نمایش استارت:** متن فعلی را با نام و موجودی حساب ادمین نمایش می‌دهد؛ هیچ تنظیمی را ذخیره نمی‌کند و برای مشتری‌ها ارسال نمی‌شود.
- **🏷 نام برند / 💬 شعار برند:** تنظیم عنوان و پیام کوتاه معرفی.
- **📞 راه ارتباطی پشتیبانی / 🕒 ساعت پاسخ‌گویی:** درج آیدی، توضیح راه ارتباطی و ساعت واقعی پاسخ‌گویی.
- ارسال متن معمولی در صفحهٔ ویرایش، قالب سفارشی را ذخیره می‌کند. پس از انتخاب یکی از پارامترها، پیام بعدی مقدار همان پارامتر است.
- پس از ذخیره، پیش‌نمایش می‌آید و دکمه‌های ویرایش دوباره در دسترس‌اند. «لغو» به تنظیمات برمی‌گردد؛ تغییرهای قبلاً ذخیره‌شده را undo نمی‌کند.

**متن سفارشی فعلی با آپدیت خودکار پاک نمی‌شود.** برای رباتی که متن قدیمی دارد، یک‌بار «قالب پیشنهادی» را انتخاب کنید. ربات بدون متن سفارشی، خودکار قالب جدید را استفاده می‌کند.

تنظیمات به `bot_id` وابسته‌اند؛ برند و قالب ربات اصلی و نمایندگی‌ها جدا ذخیره می‌شوند. پارامترها از داخل پنل تغییر می‌کنند و نیازی به ویرایش `.env` یا restart برای هر تغییر نیست.

## متغیرها

| متغیر | محتوا |
|---|---|
| `{name}` / `{first_name}` | نام کاربر |
| `{full_name}` | نام و نام خانوادگی |
| `{id}` | شناسهٔ عددی تلگرام کاربر |
| `{username}` | نام کاربری بدون @؛ در نبود آن «بدون نام کاربری» |
| `{credit}` | موجودی با جداکنندهٔ هزارگان و حفظ اعشار تومان |
| `{bot_name}` | نام نمایشی ربات در تلگرام |
| `{bot_username}` | نام کاربری ربات بدون @ |
| `{brand}` | نام برند تنظیم‌شده؛ در نبود آن نام نمایشی همین ربات |
| `{tagline}` | شعار برند |
| `{support}` | توضیح یا آیدی پشتیبانی |
| `{support_hours}` | ساعت پاسخ‌گویی تنظیم‌شده |
| `{services}` | فقط سرویس‌های فعال همین ربات؛ ویس، گروه، کانال و چت ویس |
| `{date}` | تاریخ شمسی به وقت تهران |
| `{time}` | ساعت تهران با قالب HH:MM |

مثلاً برای موجودی نمونهٔ کاربر، `{credit}` به **90,945,050.53** تبدیل می‌شود. داخل قالب دوباره آن را گرد نکنید.

## قالب آمادهٔ قابل کپی

این متن HTML را می‌توانید مستقیماً در ویرایشگر استارت ارسال کنید؛ یا همان دکمهٔ «قالب پیشنهادی» را بزنید:

```html
👋 <b>{name} عزیز، خوش آمدید!</b>

💎 <b>{brand}</b>
<i>{tagline}</i>
━━━━━━━━━━━━━━
🎯 <b>خدمات در دسترس شما</b>
{services}

💳 <b>کیف پول شما</b>
موجودی: <code>{credit}</code> تومان
شناسه کاربری: <code>{id}</code>
━━━━━━━━━━━━━━
✨ <b>از انتخاب تا پیگیری، همین‌جا</b>
۱. از «🛍 خرید سرویس» پلن دلخواهتان را انتخاب کنید.
۲. جزئیات و مبلغ را بررسی و سفارش را ثبت کنید.
۳. وضعیت را از «📦 سفارشات من» دنبال کنید.

📞 <b>کنار شما هستیم</b>
{support}
🕒 {support_hours}

👇 <b>برای شروع، از منوی پایین انتخاب کنید.</b>
```

بهتر است ساعت پشتیبانی را واقعاً تنظیم کنید؛ پیش‌فرض ادعای پشتیبانی ۲۴ ساعته، امنیت مطلق یا ممبر واقعی نمی‌کند. ادیت کردن نام برند/شعار فقط در قالبی دیده می‌شود که متغیر مربوط را داشته باشد؛ قالب‌های قدیمیِ کاملاً ثابت با تغییر پارامتر خودبه‌خود بازنویسی نمی‌شوند.

## سازگاری، امنیت و محدودیت‌ها

- نام کاربر و سایر مقادیر متغیرها متن ساده‌اند و برای HTML escape می‌شوند؛ نام دارای `&`، `<`، ایموجی یا Markdown ظاهر قالب را خراب نمی‌کند. مقدار متغیر دوباره به‌عنوان قالب تفسیر نمی‌شود.
- قالب سفارشی قدیمی حفظ می‌شود. Markdown قدیمی پیش از جایگذاری نام کاربر به HTML تبدیل می‌شود؛ HTML و Markdown را در یک قالب مخلوط نکنید. از HTML تلگرام، نه HTML دلخواه مرورگر، استفاده کنید.
- متغیر ناشناخته، عبارت‌های format/دسترسی به ویژگی مانند `{name.__class__}`، آکولاد ناقص و تگ‌های نامتوازن در ذخیرهٔ جدید رد می‌شوند. برای نمایش آکولاد معمولی از `{{` و `}}` استفاده کنید.
- قالب حداکثر ۲۵۰۰ نویسه و هر پارامتر برند/پشتیبانی حداکثر ۱۲۰ نویسه است. اگر بسط یک قالب قدیمی/تکراری از بودجهٔ امن ۳۹۰۰ واحد UTF-16 فراتر برود، به‌جای برش HTML، طرح استاندارد نمایش داده و هشدار در لاگ ثبت می‌شود؛ قالب ذخیره‌شده پاک نمی‌شود.
- موجودی از همان کیف پول فعلی می‌آید؛ این تغییر مالی نیست. ثبت کاربر، بررسی امنیتی، منوی کاربر/ادمین و دکمهٔ اختیاری چت ویس حفظ شده‌اند.
- تنظیمات استارت و سرویس‌ها با یک query محدود و tenant-scoped خوانده می‌شوند؛ برای خواندن نام ربات درخواست اضافهٔ Telegram انجام نمی‌شود.
- پیام و دکمه‌ها از همان لایهٔ پریمیوم قبلی عبور می‌کنند. نمایش ایموجی سفارشی تابع تنظیمات و مجوز تلگرام است و fallback عادی حفظ شده است.

## تست و نصب

**۳۴۳ تست موفق بدون skip، شامل ۳۰ تست PostgreSQL واقعی.** این قابلیت ۲۶ تست جدید دارد: قالب و escape، قالب قدیمی، اعشار موجودی، سرویس‌های غیرفعال، ساعت تهران، سقف طول، مسیرهای پنل، مجوز ذخیره، حفظ منو و خواندن تک-query تنظیمات مستقل نمایندگی. تلگرام در تست‌ها mock است؛ نصب یا تست زنده روی سرور مشتری انجام نشده است.

migration جدید لازم نیست. راهنمای [نصب امن نسخهٔ قبلی](REPORT_TIMING_FIX_2.2.10_FA.md#نصب-امن) همچنان معتبر است: تعمیرات، اتمام سفارش‌های فعال، بکاپ، سپس pull همین برنچ و build سرویس bot. در لاگ نسخهٔ **2.2.11** را بررسی کنید و بعد قالب جدید را از پنل فعال کنید. ادامهٔ خودکار اتصال پس از restart هنوز پیاده‌سازی نشده؛ قطع سفارش برای آپدیت توصیه نمی‌شود.
